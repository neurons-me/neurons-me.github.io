.me — lineage

me.explain(path)

me.explain("some.path");
// → { value, derivation, meta: { k, recomputed, sourcePath } }

Returns the actual computation that produced the value at path — which write triggered it, which nodes recomputed, and how many (k). Not a self-report generated after the fact.
